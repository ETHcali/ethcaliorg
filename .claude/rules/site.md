# ethcali.org — what bites

Next.js 16 Pages Router, bilingual, dark-only, the same `@ethcali/design-tokens` as the
wallet app. Workspace rules: `../CLAUDE.md`. Human overview: `README.md`.

## Verification (all three — typecheck alone misses a broken static export)

```bash
npm run typecheck
npm run check     # date and locale helper assertions
npm run build     # builds every event page in both locales
```

## Rules

- **Spanish is the default locale and carries no URL prefix.** `/events` is Spanish,
  `/en/events` English, because that is what the old site published. A missing English
  string falls back to Spanish rather than rendering blank.
- **Content lives in Supabase, not in the repo** — events, venues, team, partners — read at
  build time with the anon key and re-fetched every 60 s by ISR. No service-role key and no
  write path here. Editing happens in the wallet app: `/admin/content` (events, venues,
  partners) and `/admin/team` (the team), behind an on-chain ADMIN_ROLE check.
- **`team_members` is read with `select *`.** Whatever column exists there is published; private
  contact details live in `team_member_contacts`, which this site cannot read. Do not widen that.
- **Campaign content lives in `content/`** and belongs in git: the Builders Tour
  (`content/builders-tour.ts`), Frontier Cities (`content/quest.ts`), the hardware inventory.
  It goes out on paid traffic with fixed dates, so every change is reviewed in a diff.
- **Slugs are permanent.** They are the URL and the `og:url`. Renaming a route means a 308 in
  `next.config.js`; never leave a published URL 404ing, never add a 308 to a page that does
  not exist yet.
- **`vercel.json` is load-bearing.** The Vercel project's Framework Preset is still *Other*,
  which serves `public/` and 404s every route while the build log stays green. The one line
  in that file overrides it.
- **`AGENTS.md` and `CLAUDE.md` are generated by `next dev`** on every run. Commit them with
  your work; deleting them from a diff only recreates them. Put repo rules here, in
  `.claude/rules/`, not in those files.
- **`content/*.generated.ts` are written by scripts.** Regenerate them; do not hand-edit, and do
  not sweep an unrelated regenerated file into your commit.

## Pull requests

Hand the owner the Vercel preview URL (project `ethcaliorg`) and the page to open, not only the
GitHub link. The owner merges.
